🛠️ Outils VTT (Ligne 1)
Tous les outils de manipulation de carte. Cliquer sur un outil l'active (surligné en doré). Visible uniquement quand une carte est chargée.
👆 Sélection👁️ Révéler zone⬛ Cacher zone ▭ Zone rect.📏 Mesurer📍 Ping joueur 💫 Sorts AOE✏️ Dessin libre🧱 Murs LOS ☀️🌧️❄️🌫️🔥 Météo⚔️ Combat 🗺️ Terrain (glisser)🖼️💾 Export PNG
2
⚙️ Outils de session (Ligne 2)
Outils de gestion de session, audio, tokens, communication avec les joueurs. Toujours visible.
🗺️ Changer de carte🎵🎶 Musique 2 pistes #️⃣ Grille (taille)🕶️ Écran noir ⏱️ Timer session⏳ Compte à rebours 🧟 PNJ rapide💰 Butin📤 Handout 🕸️ Relations PNJ📜 Log combat 💥 Calculateur dégâts⚡ Générateur rencontre 🏚️ Générateur salle🌦️ Météo planner ⏱️ Durées📋 Notes partagées 👥 Groupe📱 Hub mobile 🔦 Spotlight token
3
🗂️ Onglets de scènes
Chaque scène est un onglet avec sa propre carte, ses tokens, son brouillard de guerre et ses épingles. Cliquer bascule entre les scènes. Le + ajoute une nouvelle scène.
4
📁 Sidebar — Vault de fichiers
Arborescence des notes et assets de la campagne. Clic droit → Nouveau fichier. Le bouton vert Lancer Vue Joueurs ouvre la fenêtre de projection pour les joueurs.
5
🗺️ Zone de carte (Canvas PixiJS)
Zone interactive principale. Scroll = zoom · Clic molette ou clic droit = pan (déplacer la vue) · Ces déplacements sont synchronisés en temps réel sur l'écran des joueurs.
🔍 Zoom min/max : 5% – 800% 📡 Sync temps réel joueurs
6
➡️ Chemin de déplacement
Quand vous faites glisser un token, une ligne pointillée dorée indique le chemin et le nombre de cases parcouru. Pratique pour respecter les règles de mouvement.
7
❤️ Barre de HP sur les tokens
Visible par les joueurs ET le MJ. La largeur est proportionnelle à la taille du token. Couleur : vert >50%, jaune 20–50%, rouge <20%.
8
📊 Tableau de bord de session
Flottant en haut à droite. Affiche le round actuel (R.1, R.2…), le timer, la météo, les boutons ◀▶ de tour, et la liste des combattants avec leurs HP. Cliquer sur 📜 ouvre le mini-log de combat.
9
⚡ Barre de macros
Boutons de commandes rapides. Chaque macro a une icône + étiquette. Drag-and-drop pour réorganiser. Clic droit sur une macro pour la modifier. Le champ texte accepte des commandes directes.
/roll 2d10/heal group 5 /anim attackDrag-and-drop
10
🗺️ Minimap
Vue d'ensemble de la carte en bas à droite. Montre la position de la caméra actuelle par rapport à la carte entière.

② Vue Éditeur — Notes & Campagne

Accessible quand aucune carte n'est chargée, ou en fermant le VTT. Centralise toutes vos notes de campagne.

1
🛠️ Barre d'outils simplifiée
Quand aucune carte n'est active, la toolbar n'affiche que les outils de session : changer de carte, audio, timer, outils GM (PNJ, Butin, Handout), titre de campagne et texte d'ambiance.
2
🎯 Bouton Vue Joueurs
Le bouton 🎭 (surligné en doré) lance ou met au premier plan la fenêtre de projection. Cette fenêtre est celle que vos joueurs voient sur un écran secondaire ou en partage d'écran.
3
📂 Onglets de modes
Bascule entre les quatre vues principales de l'éditeur.
📝 Éditeur Notes Markdown avec rendu en direct 🌐 Graphe Réseau visuel des notes liées 📅 Timeline Chronologie des événements 🗓️ Calendrier Calendrier de campagne personnalisé
4
📁 Gestionnaire de fichiers
Arborescence complète de votre vault. Le champ de filtre cherche dans les noms de fichiers en temps réel. Clic droit sur un dossier pour créer/renommer/supprimer. Le bouton Réindexer reconstruit le graphe de liens.
5
✏️ Zone d'édition
Éditeur Markdown avancé (CodeMirror). Supports : syntaxe WFRP, liens wiki [[Nom]], titres, listes, tableaux, blocs de code. L'IA Ollama (Ctrl+J) peut générer du contenu de campagne.
6
⌨️ Raccourcis clavier
Affichés dans l'état vide. Tous les raccourcis fonctionnent depuis n'importe où dans l'éditeur.

③ Référence rapide

🗺️ Navigation carte

  • 🖱️ Scroll — Zoom in/out (5% – 800%)
  • 🖱️ Clic molette + drag — Déplacer la vue
  • 🖱️ Clic droit + drag — Déplacer la vue (alt)
  • 🖱️ Drag token — Déplacer (snap grille + chemin)
  • ⇧ Shift + clic token — Multi-sélection
  • 🖱️ Clic droit token — Roue des conditions (🎡)
  • ⇧🖱️ Shift + clic droit — Paramètres du token

⌨️ Raccourcis globaux

  • Ctrl+N — Nouveau fichier
  • Ctrl+P — Palette de recherche
  • Ctrl+S — Sauvegarder
  • Ctrl+J — Générer avec IA (Ollama)
  • Ctrl+Z — Annuler action VTT
  • Ctrl+Clic — Suivre lien wiki [[…]]
  • Esc — Fermer modale ouverte

⚔️ Combat

  • Démarrer le combat depuis l'outil ⚔️
  • Les tokens sont importés automatiquement
  • ◀ ▶ dans le dashboard pour changer de tour
  • Le round s'incrémente automatiquement
  • R.1, R.2… visible par les joueurs
  • HP bas = mort automatiquement logguée (💀)

🎲 Commandes macros

  • /roll 2d10+5 — Jet de dés
  • /roll 1d100 — Jet percentile
  • /heal group 5 — Soin de tous les alliés
  • /anim attack — Animation attaque
  • /anim hit — Animation touché
  • Clic droit → éditer icône/nom/commande

③ bis — Outils MJ (Wave 10 + 13)

💥 Calculateur de Dégâts

  • Saisir une formule : 2d6+4, 1d10…
  • Sélectionner une ou plusieurs cibles dans l'initiative
  • Option "Demi-dégâts" (sorts de sauvegarde)
  • Applique HP et logue dans le combat log

📋 Notes Partagées

  • Saisir un titre et un corps de note
  • Envoyer d'un clic → overlay sur l'écran joueur
  • Les joueurs ferment eux-mêmes la note
  • Historique des notes envoyées dans le modal

⏱️ Suivi des Durées

  • Présets rapides : 🕯️ Torche, ✨ Lumière magique, 🔮 Concentration…
  • Ajout manuel : icône + label + nombre de rounds
  • Barre de progression colorée (vert → rouge)
  • Pulse rouge urgent à ≤1 round restant
  • "-1 Round" pour tout avancer simultanément

🌦️ Planificateur Météo

  • Planifier jusqu'à 7 jours de météo
  • 6 types : Dégagé, Pluie, Neige, Brouillard, Tempête, Braises
  • Narration automatique par type
  • ▶ Appliquer : applique sur la carte immédiatement
  • 📋 Copier MD : exporte le plan en Markdown

⚡ Générateur de Rencontre

  • Lieu (12 options) × Moment (7) × Menace (15) × Rebondissement (10)
  • Bouton 🎲 pour relancer chaque facteur
  • Intensité : Mineure → Légendaire
  • 📋 Copier pour coller dans vos notes

🏚️ Générateur de Salle

  • Forme + Taille + Usage + Éclairage
  • Odeur + Son ambiant + Sorties + Contenu
  • Piège possible + Objet caché
  • Bouton 🎲 pour regénérer, 📋 pour copier

👾 Pack Mimic (Wave 13)

  • 4 tokens illustrés : Coffre, Porte, Baril, Table
  • Intégrés dans la bibliothèque de monstres (🐉)
  • Prêts à spawner avec stats (PV, CA, Taille)
  • Format circulaire optimisé pour le VTT
🖱️ Interactions Avancées — Tokens
Clic droit sur un token
  • → Roue de Conditions (8 conditions radialement)
  • → Cliquer une condition pour la toggler
  • → Bouton 🗑️ au centre pour supprimer le token
  • → Cliquer en dehors pour fermer
Shift + Clic droit
  • → Ouvre Paramètres du Token
  • → HP/MaxHP, conditions + durées, concentration
  • → Aura, lumière, note, lien wiki
Drag token (mode sélection)
  • → Chemin jaune pointillé affiché
  • → Compteur "N cases" en temps réel
  • → Snap sur la grille à la release
Mode Terrain (🗺️)
  • → Choisir type : 🏔️ Difficile, 🌊 Eau, 🔥 Feu…
  • → Drag pour dessiner le rectangle
  • → Zone colorée semi-transparente avec label
🌫️ Brouillard de Guerre — Comportement (Wave 13)
Visibilité des tokens
  • → Tokens cachés dans toute zone non révélée
  • → Tokens visibles uniquement dans les zones 👁️ révélées
  • → Zone ⬛ hide masque un token même dans une zone révélée
  • → Token.visible=false = toujours caché (masque MJ)
Toggle 🌫️ (activer/désactiver)
  • → Désactiver : carte et tokens entièrement visibles
  • → Réactiver : repart de zéro — tout caché
  • → Les formes précédentes sont effacées au toggle ON
  • → Redessiner les zones révélées avec 👁️

④ Flux de travail GM typique

1
Préparer la session
Onglet AdventureLibrary (📚) → ouvrir un scénario → remplir l'objectif de session, les actes, les PNJs clés. Utiliser 🕸️ Relations PNJ pour mapper les connexions entre personnages importants.
2
Lancer la session
Charger la carte (bouton 🗺️ ou onglet de scène) → cliquer 🎭 Lancer Vue Joueurs → projeter la fenêtre joueur → démarrer le timer ⏱️.
3
Explorer et narrer
Utiliser 👁️ pour révéler les zones au fil de l'exploration. Placer des 📌 épingles avec descriptions. Utiliser le champ Texte d'ambiance pour afficher des textes narratifs sur l'écran joueur. Envoyer des handouts 📤 pour des images ou documents.
4
Combat
Spawner des tokens ennemis avec 🧟 PNJ rapide (auto-taille sur la grille) → ⚔️ Démarrer combat → les joueurs voient le tracker d'initiative avec le round. Modifier les HP dans le tableau de bord, consulter le 📜 log de combat en temps réel.
5
Fin de session
Onglet 📚 AdventureLibrary → section Journal de session → noter résumé, joueurs présents. Cliquer Export MD pour copier le résumé en Markdown. Exporter les stats via 📊 SessionExport.
